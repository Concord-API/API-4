## **US 7 - Tela para Técnicos**
**Prioridade: Alta — Estimativa: 5**

-O sistema deve disponibilizar tela de login.

-O sistema deve ter uma tela voltada para o Técnico.

-Campos obrigatórios: e-mail e senha.

-Login deve validar credenciais contra banco de dados.

-Após login, o sistema deve direcionar o usuário para a tela de acordo com seu cargo e de acordo com sua credencial.

-Tentativas inválidas devem gerar mensagem de erro.


---
# **US 8 - Deploy**
**Prioridade: Média — Estimativa: 3**

-O sistema deve estar disponível para ser acessado de forma online.

-Os dados devem ser de um banco de dados existente. 

-O servidor deve estar online na Oracle.


---
# **US 9 - Geração de manutenção**
**Prioridade: Alta — Estimativa: 8**

-O Sistema deve criar uma manutenção de acordo com o contrato.

-A Manutenção deve ter a data limite para a manutenção ser feita.

-A Manutenção deve ter um campo para marcar a data que será feita a manutenção.

---
## **US 10 - Mapa navegável**
**Prioridade: Baixa — Estimativa: 8**

-A tela deve conter um mapa navegável.

-O mapa deve apresentar informações da localização de manutenções.
